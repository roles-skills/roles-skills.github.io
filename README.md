# roles-skills.github.io

The website for the [digital health care job roles reference](https://github.com/roles-skills/roles-skills): plausible job roles, bands, responsibilities, skills, and job evaluation scores for a generic digital health care organisation, aligned with the UK Government Digital and Data Profession Capability Framework and ESCO.

Published at <https://roles-skills.github.io>.

> **This repository is a read-only export.** It is published from the `roles-skills.github.io/` directory of the [monorepo](https://github.com/roles-skills/roles-skills) by `git subtree`. Do not commit here: the next publish would be rejected. Make every change in the monorepo.

## Build

Requires Node.js 26 and pnpm.

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm check
pnpm build      # build/
```

GitHub Actions (`.github/workflows/deploy.yml`) builds every push to `main` and deploys `build/` to GitHub Pages.

## Content manager

Sveltia CMS at <https://roles-skills.github.io/admin/> edits the monorepo's `data/` through the GitHub backend. Its configuration, `static/admin/config.yml`, is generated by the monorepo's `scripts/cms_config.py`.
